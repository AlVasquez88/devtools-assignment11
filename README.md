# YAML File Automator for Assignment 11 Part A
Alvin Vasquez

## This is my attempt to use a YAML file to automate and run a python file with 3 test cases. It does the following:
+ test case 1 tests for numbers ranging 1 - 10.
+ test case 2 tests for one number in the text file.
+ test case 3 tests if the text file is blank.

To see the yml file in action, go to **Actions** then click on the latest commit to see the test cases.
